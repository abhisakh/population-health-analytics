# Population Health Analytics
 
## Overview
 
Population Health Analytics is an end-to-end healthcare analytics project that explores patient demographics, disease burden, healthcare utilization, and regional cost patterns across Germany.
 
The project combines Power BI and Tableau to deliver both executive-level reporting and exploratory analytics, helping stakeholders identify key trends in healthcare service usage and treatment outcomes.

## Business Problem
 
Healthcare organizations need actionable insights into:
 
- Disease burden across regions
- Healthcare utilization patterns
- Demographic differences in patient populations
- Hospital cost distribution
- Socioeconomic influences on healthcare access
 
This project demonstrates how analytics can support data-driven healthcare planning and resource allocation.

## Key Insights
 
### Regional Analysis
- NRW has the largest patient population.
- Regional disease burden varies across federal states.
- Healthcare utilization differs significantly by region.
 
### Socioeconomic Factors
- Healthcare utilization varies across income quartiles.
- Demographic patterns influence healthcare demand.
 
### Cost Analysis
- Hospital costs are not evenly distributed across regions.
- Certain regions contribute disproportionately to total healthcare expenditure.
